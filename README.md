# mini-drum_practice

브라우저에서 바로 하는 드럼 리듬 연습 웹앱입니다. 레벨 1~7과 단계별 연습(2.x~7.x, 모두 31단계, 레벨 묶음 탭으로 선택), 세로(기본)·가로 레인, 키보드·터치·MIDI 전자드럼 입력, 판정·점수·속도 조절, 탭 레이턴시 보정, 엑셀 스킨을 지원합니다.

- 키보드(기본값, 드럼 순서): D 하이햇 · F 스네어 · Space 킥 · J 탐 · K 크래시. 화면의 "키 설정"에서 바꿀 수 있습니다.
- MIDI 전자드럼은 Chrome·Edge에서 동작합니다.
- 설치나 빌드 없이 `index.html` 한 파일로 동작합니다.
